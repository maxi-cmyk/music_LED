Fourier matrix

Input: One column of 128 samples. is sample (0–127). Here its value is generated and unitless; the 128 samples span 20 ms.
Why 128 × 128? Four sample values contain four pieces of information. Each test row uses all four values (four columns); four independent pattern tests give four results that can rebuild them (four rows). With 128 samples, the same rule gives 128 columns and 128 rows. These rows test patterns numbered 0–127. Pattern 128 repeats pattern 0 at the sampled points, so it adds nothing new.
Output: Row gives ; its magnitude is that pattern’s strength (unitless here). For real input, bins 65–127 mirror bins 63–1, so we show 0–64.

How does the microphone produce ?

Sound changes air pressure; the microphone turns that into a changing voltage. The ESP32 converts each voltage measurement to a raw ADC count from 0 to 4095. It subtracts the frame average and softens the frame edges before calculating the transform. Prepared and the resulting have ADC-count units; the weights have no unit. The toy values above are generated and unitless.
