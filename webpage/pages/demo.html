128 samples produce 128 DFT rows

Each row multiplies all 128 samples and produces one coefficient . The row number and bin number are the same index.

Why does the selectable spectrum stop at bin 64?

The microphone samples are real numbers, so rows 65–127 mirror rows 63–1 with the same magnitudes. Nothing is missing: rows 0–64 are the 65 unique results. Row 0 is DC, rows 1–63 are positive frequencies, and row 64 is the Nyquist limit.

The FFT reuses partial DFT results

A twiddle factor is a complex rotation that supplies the phase needed when an even-indexed result and an odd-indexed result are combined. One rotated odd value is reused to produce two coefficients.

Three band strengths become RGB

First, the magnitudes inside each fixed bin range are combined into the three-entry band vector .

Red · bass
Green · mids
Blue · treble
  1. Apply fixed colour gains. The input and output each contain three values—red, green and blue—so their mapping matrix is 3 × 3. It is a chosen LED-calibration matrix, not part of the Fourier matrix.
  2. Remove weak leakage. Find the strongest value in , then subtract 15% of it from all three channels. Negative results become zero. Dividing by 0.85 keeps the strongest channel unchanged; is the cleaned colour-strength vector.
  3. Set LED brightness. Multiply by 0.12, then apply the ceiling function so any fraction rises to the next integer. Finally, limit each PWM value to 0–255.
Band vector → gains → leakage suppression → PWMThe DFT and are linear. Magnitude, band aggregation, leakage suppression, ceiling and clipping are not.
